Below is a **V1 high-ROI optimization recipe** that keeps the core of the methodology but removes most of the expensive machinery. The original method is a localized low-rank pursuit over unknown contiguous windows, with optional hierarchy, sparse activation, block-coordinate refitting, and split–merge–prune model selection; V1 should focus on discovering useful windows and fitting rank-2 local events reliably first. 

# V1 optimization recipe: fixed-rank localized low-rank pursuit

## 0. V1 design decision

For V1, use this simplified model:

[
X \approx \sum_{k=1}^{K} Z_k V_k^\top + E
]

where:

[
X \in \mathbb{R}^{n \times M}
]

is the aligned residual matrix, with rows as flights and columns as stations along the reference path.

Each event (k) has:

[
(I_k, V_k, Z_k)
]

where:

[
I_k=[a_k,b_k]
]

is a contiguous station interval,

[
V_k \in \mathbb{R}^{M \times 2}
]

is zero outside (I_k), and

[
Z_k \in \mathbb{R}^{n \times 2}
]

contains the per-flight event coordinates.

You are fixing:

[
d_k=d_{\max}=2
]

for every event, so remove:

[
\lambda_d \sum_k d_k
]

from the objective.

The V1 objective is therefore:

[
\min_{{I_k,V_k,Z_k}}
\frac12
\left|
X-\sum_{k=1}^{K}Z_kV_k^\top
\right|*F^2
+
\lambda_0K
+
\lambda_I\sum_k |I_k|
+
\lambda_A\sum*{i,k}\mathbf{1}{|Z_{ik}|_2>0}
]

with:

[
\operatorname{supp}(V_k)\subseteq I_k,
\qquad
V_{k,I_k}^\top V_{k,I_k}=I_2.
]

For V1, I would **not** include full roughness-penalized PCA yet. If the components look jagged, add smoothing later. The first test should answer:

> Can simple localized rank-2 windows explain useful trajectory variation?

---

# 1. What to keep and what to skip in V1

## Keep

Keep only the highest-ROI pieces:

1. **Normal-only residual matrix** first.
2. **Fixed rank (d=2)** for every event.
3. **Variance-peak / narrowest-over-threshold candidate generation**.
4. **Local rank-2 SVD scoring**.
5. **Greedy residual pursuit**.
6. **Simple per-flight activation thresholding**.
7. **Cheap final fixed-basis coefficient refit**.

## Skip for now

Skip these in V1:

1. Full block-coordinate refitting of (Z_k,V_k,I_k).
2. Full split–merge–prune.
3. Beam search.
4. WBS/random intervals.
5. Covariance-connected interval search.
6. Polyline/heading candidate generation.
7. Explicit broad/local hierarchy.
8. Tensor normal/tangential formulation.

The only exception: keep a **very cheap large-window guardrail** through narrowest-over-threshold candidate selection. That gives you most of the benefit of split testing without implementing the full split–merge–prune system.

---

# 2. Data preprocessing

For each route class, align every trajectory to a reference path and compute residuals.

Start with the normal deviation only:

[
a_i(s)=u_i(s)\cdot N(s)
]

Discretize at (M) stations:

[
X_{ij}=a_i(s_j)
]

so:

[
X\in\mathbb{R}^{n\times M}.
]

Then robust-center each station:

[
X_{\cdot j}
\leftarrow
X_{\cdot j}
-----------

\operatorname{median}*i(X*{ij})
]

or use the mean if the data are already well-cleaned.

Estimate a residual noise scale:

[
\hat\sigma
==========

\frac{
\operatorname{MAD}\left(X_{i,j+1}-X_{ij}\right)
}{
0.6745\sqrt{2}
}
]

using all adjacent station differences. This gives a rough scale for deciding whether a fitted local event is real or just noise.

---

# 3. Simplified candidate generation

This is the most important simplification.

Do **not** search all (O(M^2)) intervals.

For each residual matrix (R), compute the stationwise residual energy:

[
e_j
===

\frac{1}{n}\sum_{i=1}^{n}R_{ij}^2.
]

Smooth it lightly:

[
\tilde e_j = \operatorname{Smooth}(e_j)
]

using a small moving average or Savitzky–Golay filter.

Find local peaks of (\tilde e_j). Keep only peaks satisfying:

[
\tilde e_j

>

\operatorname{median}(\tilde e)
+
\kappa_{\text{peak}}\operatorname{MAD}(\tilde e)
]

with a starting value:

[
\kappa_{\text{peak}}=2.
]

Also enforce a minimum separation between peaks, for example:

[
\text{min_peak_distance}
========================

\left\lceil 0.5L_{\min}\right\rceil.
]

Recommended initial lengths:

[
L_{\min}=\max(5,\lceil 0.02M\rceil)
]

[
L_{\max}=\lceil 0.25M\rceil.
]

Use a short length grid:

[
\mathcal{L}
===========

{L_{\min}, 2L_{\min}, 4L_{\min}, 8L_{\min}, \ldots, L_{\max}}.
]

For each peak (p), create centered intervals:

[
I(p,L)
======

[p-\lfloor L/2\rfloor,\ p+\lceil L/2\rceil-1]
]

clipped to ([1,M]).

Then apply the **narrowest-over-threshold rule**:

> For each peak, evaluate candidate intervals from shortest to longest. Keep the first interval whose local rank-2 score is positive. Optionally also keep the next longer interval as a backup.

This is the V1 substitute for full split testing.

It prevents this failure mode:

[
\text{large window containing several unrelated local events}
]

because a smaller interval around the actual feature gets selected first.

---

# 4. Local rank-2 fit for one candidate interval

Given residual (R) and candidate interval (I), extract:

[
R_I \in \mathbb{R}^{n\times |I|}.
]

Compute the rank-2 SVD:

[
R_I = U\Sigma W^\top.
]

Take:

[
W_2 = W[:,1:2]
]

[
V_{I}=W_2
]

and embed it into the full station space by setting (V_j=0) outside (I).

The corresponding per-flight scores are:

[
Z=R_IW_2.
]

Without sparse activation, the explained residual energy is:

[
\Delta(I)
=========

\sigma_1^2+\sigma_2^2.
]

With activation thresholding, use:

[
z_i = Z_{i,\cdot}\in\mathbb{R}^2
]

and define active flights as:

[
|z_i|_2

>

\tau_z.
]

A good starting threshold is:

[
\tau_z
======

\hat\sigma\sqrt{\chi^2_{2,0.95}}
\approx
2.45\hat\sigma.
]

Set inactive rows of (Z) to zero.

Then recompute the actual fitted gain:

[
\Delta_{\text{active}}(I)
=========================

|ZV_I^\top|_F^2.
]

Use (\Delta_{\text{active}}) for scoring.

Also require a minimum number of active flights:

[
n_{\text{active}}
\geq
n_{\min}
]

with:

[
n_{\min}=\max(5,\lceil 0.01n\rceil).
]

This avoids selecting an “event” caused by one or two unusual flights.

---

# 5. V1 scoring function

For V1, use a simple score:

[
\operatorname{score}(I)
=======================

## \Delta_{\text{active}}(I)

## \lambda_0

## \lambda_I |I|

\lambda_A n_{\text{active}}.
]

Because (d=2) is fixed, there is no (\lambda_d) term.

A practical starting version is:

[
\operatorname{score}(I)
=======================

## \Delta_{\text{active}}(I)

## T_{\text{null}}(|I|)

\lambda_I |I|.
]

Here (T_{\text{null}}(|I|)) is a length-specific noise threshold.

The easiest way to get (T_{\text{null}}) is empirical:

1. Randomly sign-flip rows of (R), or circularly shift each row by a random station offset.
2. Generate the same type of candidate intervals.
3. Compute rank-2 gains.
4. For each length (L), set:

[
T_{\text{null}}(L)
==================

q_{0.99}\left(\Delta_{\text{null}}(L)\right).
]

Use 20 to 50 null repeats. This is much easier to tune than a hand-derived BIC penalty and automatically accounts for the fact that you are scanning many candidate windows.

If you do not want null calibration yet, use a crude analytic fallback:

[
T_{\text{null}}(L)
==================

c_{\text{null}}\hat\sigma^2(n+L)
]

with:

[
c_{\text{null}}\in[3,6].
]

For a first implementation, I would use:

[
\lambda_I = 0
]

if using narrowest-over-threshold. If large windows still dominate, set:

[
\lambda_I = c_I\hat\sigma^2n
]

with:

[
c_I\in[0.01,0.1].
]

# 6. Greedy residual pursuit

Initialize:

[
R^{(0)}=X
]

and active event list:

[
\mathcal{A}=\varnothing.
]

At iteration (t):

1. Generate candidate intervals from (R^{(t)}).
2. Score each candidate by local rank-2 SVD.
3. For each variance peak, keep the narrowest positive candidate.
4. From the remaining candidates, select:

[
I^\star
=======

\arg\max_I \operatorname{score}(I).
]

5. If:

[
\operatorname{score}(I^\star)\leq 0
]

stop.

6. Add the event:

[
\mathcal{A}
\leftarrow
\mathcal{A}\cup{I^\star,V^\star,Z^\star}.
]

7. Update the residual:

[
R^{(t+1)}
=========

## R^{(t)}

Z^\star {V^\star}^\top.
]

8. Continue until one of these stopping conditions is met:

[
\max_I \operatorname{score}(I)\leq 0
]

or

[
K=K_{\max}
]

or the last event explains less than a small fraction of the original energy:

[
\frac{\Delta_{\text{active}}(I^\star)}{|X|*F^2}
<
\epsilon*{\text{gain}}.
]

Use:

[
\epsilon_{\text{gain}}=0.001
]

as a starting value.

A reasonable starting cap is:

[
K_{\max}=25
]

or:

[
K_{\max}=\left\lceil \frac{M}{L_{\min}}\right\rceil.
]

---

# 7. Duplicate and overlap control

Without full split–merge–prune, add one cheap duplicate-control rule.

When a new candidate (I) overlaps an already-selected interval (I_k), compute intersection-over-union:

[
\operatorname{IoU}(I,I_k)
=========================

\frac{|I\cap I_k|}{|I\cup I_k|}.
]

Reject (I) as a duplicate if:

[
\operatorname{IoU}(I,I_k)>0.8
]

and:

[
0.5
<
\frac{|I|}{|I_k|}
<
2.
]

This still allows true nested events, because a much shorter child event inside a broad parent is not automatically rejected.

For V1, do **not** implement merge. Let the test results tell you whether merge is needed.

---

# 8. Cheap event trimming

After selecting an event, trim weak endpoints.

For selected event (k), compute the stationwise fitted event energy:

[
g_j
===

|Z_k V_{k,j}^\top|_2^2
]

for (j\in I_k).

Starting from the left endpoint, remove stations while:

[
g_j
<
\eta_{\text{edge}}\operatorname{median}*{\ell\in I_k}(g*\ell)
]

and the remaining interval length is still at least (L_{\min}).

Do the same from the right endpoint.

Use:

[
\eta_{\text{edge}}=0.05.
]

After trimming, recompute the rank-2 SVD on the trimmed interval.

This is much cheaper than endpoint block-coordinate optimization, but it fixes many overly wide event windows.

---

# 9. Final fixed-basis coefficient refit

This is the one “refit” I would keep in V1.

It is **not** full block-coordinate refitting because you do not update intervals or basis functions. You only recompute coefficients (Z) once given the selected (V_k)’s.

Build a global dictionary:

[
D\in\mathbb{R}^{M\times 2K}
]

by concatenating the embedded basis columns:

[
D=
[V_{1,1},V_{1,2},V_{2,1},V_{2,2},\ldots,V_{K,1},V_{K,2}].
]

Then solve:

[
A
=

X D(D^\top D+\rho I)^{-1}
]

where:

[
A\in\mathbb{R}^{n\times 2K}.
]

Use a small ridge value:

[
\rho = 10^{-6}|D^\top D|_2
]

or simply:

[
\rho=10^{-6}.
]

Then recover event-specific coefficients:

[
Z_k=A[:,2k-1:2k].
]

Apply the same per-flight activation threshold:

[
|Z_{ik}|_2>\tau_z.
]

Set inactive event coefficients to zero.

This step is very high ROI because it reduces greedy order effects while avoiding the complexity of full block-coordinate refitting.

---

# 10. Final V1 output

The fitted model should return a list of events:

```text
Event k:
    interval: [a_k, b_k]
    length: L_k
    basis: V_k, shape M x 2, zero outside interval
    scores: Z_k, shape n x 2
    active_mask: n-dimensional boolean vector
    raw_gain: sigma_1^2 + sigma_2^2
    active_gain: ||Z_k V_k^T||_F^2
    score: active_gain - penalties
    active_fraction: mean(active_mask)
```

Also return:

```text
Global:
    K
    residual R
    reconstruction X_hat
    explained_fraction = 1 - ||X - X_hat||_F^2 / ||X||_F^2
    per-event explained_fraction
```

# 11. Applying the model to the test set

For the test set, do **not** rediscover intervals if you want a clean generalization test.

Given test residual matrix:

[
X_{\text{test}}\in\mathbb{R}^{n_{\text{test}}\times M},
]

use the learned dictionary (D) from training.

Compute test coefficients:

[
A_{\text{test}}
===============

X_{\text{test}}D(D^\top D+\rho I)^{-1}.
]

Apply the same activation threshold:

[
|Z_{ik}^{\text{test}}|_2>\tau_z.
]

Then reconstruct:

[
\widehat X_{\text{test}}
========================

A_{\text{test}}D^\top.
]

Measure:

[
\text{Test explained fraction}
==============================

1-
\frac{
|X_{\text{test}}-\widehat X_{\text{test}}|*F^2
}{
|X*{\text{test}}|_F^2
}.
]

Also track:

[
\text{average active events per flight}
]

and:

[
\text{active fraction per event}.
]

These will tell you whether the method is discovering reusable deformation events or simply overfitting training residuals.

# 12. Pseudocode

```python
def fit_v1_localized_low_rank(X, config):
    """
    X: n x M aligned normal-residual matrix
    returns: events, dictionary D, train reconstruction
    """

    X = robust_center_columns(X)
    sigma = estimate_noise_from_station_differences(X)

    R = X.copy()
    events = []

    for t in range(config.K_max):

        # 1. Generate peak-centered candidates
        peaks = find_residual_energy_peaks(
            R,
            L_min=config.L_min,
            kappa_peak=config.kappa_peak
        )

        candidates = []

        for p in peaks:
            # Narrowest-over-threshold search
            best_for_peak = None

            for L in config.length_grid:
                I = centered_interval(p, L, M=X.shape[1])

                fit = local_rank2_fit(
                    R,
                    I,
                    sigma=sigma,
                    tau_z=config.tau_z,
                    n_min=config.n_min
                )

                score = compute_score(
                    fit,
                    length=L,
                    sigma=sigma,
                    threshold_table=config.null_thresholds,
                    lambda_I=config.lambda_I
                )

                if score > 0:
                    best_for_peak = fit
                    break

            if best_for_peak is not None:
                candidates.append(best_for_peak)

        # 2. Remove duplicates / near-identical intervals
        candidates = suppress_duplicate_intervals(
            candidates,
            events,
            iou_threshold=0.8
        )

        if len(candidates) == 0:
            break

        # 3. Select best candidate
        best = max(candidates, key=lambda c: c.score)

        if best.score <= 0:
            break

        # 4. Trim weak endpoints
        best = trim_event_endpoints(best, R, config)

        # 5. Add event
        events.append(best)

        # 6. Greedy residual update
        R = R - best.Z @ best.V.T

        # 7. Stop if gain is tiny
        if best.active_gain / np.linalg.norm(X, "fro")**2 < config.epsilon_gain:
            break

    # 8. Fixed-basis coefficient refit
    D = build_dictionary_from_events(events)

    A = X @ D @ np.linalg.inv(D.T @ D + config.ridge * np.eye(D.shape[1]))

    A = apply_group_activation_threshold(A, sigma, events)

    X_hat = A @ D.T
    R_final = X - X_hat

    update_event_coefficients_from_A(events, A)

    return events, D, X_hat, R_final
```

# 13. Minimal parameter defaults

Use these as starting values:

```text
d = 2

L_min = max(5, ceil(0.02M))
L_max = ceil(0.25M)

length_grid = [L_min, 2L_min, 4L_min, ..., L_max]

kappa_peak = 2.0
min_peak_distance = ceil(0.5L_min)

tau_z = 2.45 * sigma_hat
n_min = max(5, ceil(0.01n))

K_max = min(25, ceil(M / L_min))

epsilon_gain = 0.001

lambda_I = 0 initially
ridge = 1e-6

endpoint_trim_threshold = 0.05
duplicate_IoU_threshold = 0.8
```

For acceptance thresholds, I recommend:

```text
Preferred:
    empirical null threshold by interval length

Fallback:
    T_null(L) = c_null * sigma_hat^2 * (n + L)
    c_null in [3, 6]
```

# 14. Should you skip block-coordinate refitting?

For V1: **yes, skip full block-coordinate refitting.**

Do not implement this yet:

[
Z\text{-update}
\rightarrow
V\text{-update}
\rightarrow
I\text{-endpoint update}
\rightarrow
\text{repeat}.
]

It is valuable later, but it is not necessary for the first test.

Instead, keep only the cheap final fixed-basis coefficient refit:

[
A
=

XD(D^\top D+\rho I)^{-1}.
]

That gives you a large fraction of the benefit with much less implementation complexity.

Add full block-coordinate refitting later only if you see these symptoms:

1. Strong dependence on event selection order.
2. Multiple overlapping events explaining the same region.
3. Train performance good but test performance poor.
4. Visually plausible windows but weak final reconstruction.
5. Broad/local interactions where the broad event absorbs local structure.

---

# 15. Should you skip split–merge–prune?

For V1: **skip full split–merge–prune**, but do **not** skip large-window protection entirely.

Use these three cheap substitutes:

1. **Narrowest-over-threshold candidate selection.**
2. **Endpoint trimming.**
3. **Duplicate overlap suppression.**

This gives you the most important part of split–merge–prune: avoiding useless large windows.

Do not implement merge yet.

Do not implement recursive split testing yet.

Add split testing later only if you observe selected intervals that visibly contain two or more unrelated deformation features.

---

# 16. V1 algorithm in one sentence

The V1 optimizer is:

[
\boxed{
\text{variance-peak candidate generation}
\rightarrow
\text{narrowest positive rank-2 SVD window}
\rightarrow
\text{greedy residual subtraction}
\rightarrow
\text{endpoint trimming}
\rightarrow
\text{fixed-basis coefficient refit}
}
]

This is the smallest version I would implement before testing.

It keeps the key idea from the full methodology—localized low-rank event discovery—but avoids the expensive outer machinery until the test-set results tell you which failure mode matters most.
